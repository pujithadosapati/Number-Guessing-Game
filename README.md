# Number Guessing Game
## Description
A simple Python game in which the computer
generates a random number between 1 and 100.
The user keeps guessing until the correct
number is found.
## Features
- Random number generation
- High and low hints
- Attempt counter
- Input validation
- Automatic game termination after a correct guess
## Technologies Used
- Python 3
- random module
## How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the command:

   python number_guessing_game.py
## Concepts Learned
- Loops
- Conditional statements
- Random number generation
- User input
- Exception handling
- Counter variables
