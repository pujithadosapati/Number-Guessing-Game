# Guessing Numbers Game
## Description
A straightforward Python game where a random number between 1 and 100 is generated by the computer.
Until the right number is discovered, the user continues to guess.
## Characteristics

Make an attempt to counterValidation of input
Automatic game termination following an accurate guess

2. In the project folder, launch a terminal.
